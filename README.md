# Bilgi Muhafızları Atölyesi  
## AI'Han Academy

**Bilgi Muhafızları Atölyesi**, çocuklara araştırma becerileri, kaynak kullanımı, bilgi doğrulama, Yapay Zekâ okuryazarlığı, gizlilik ve etik bilgi kullanımı kazandırmak amacıyla hazırlanmış etkileşimli bir öğrenme portalıdır.

Portal; **Kâşif**, **Bilge** ve **Lugat** karakterleriyle çocukları oyunlaştırılmış görevler, mini etkinlikler, araştırma dosyaları, kaynak kontrol çalışmaları, Yapay Zekâ cevabı değerlendirme bölümleri ve sertifika sistemi üzerinden yönlendirir.

---

Temel amaçlar:

- Araştırma sorusu oluşturma
- Anahtar kelime belirleme

- Kaynak güvenilirliğini değerlendirme
- Yapay Zekâ cevaplarını sorgulama
- Kişisel veri ve gizlilik farkındalığı kazanma
- Etik bilgi kullanımı becerisi geliştirme
- Öğrenilen bilgiyi kendi cümleleriyle ifade etme

# Information Guardians Workshop  
## AI'Han Academy

**Information Guardians Workshop** is an interactive educational portal designed to help children develop research skills, source evaluation habits, information literacy, Artificial Intelligence literacy, privacy awareness, and ethical information use.

The portal guides children through gamified missions, mini activities, research tasks, source-checking exercises, AI response evaluation activities, and a certificate system with the characters **Kâşif**, **Bilge**, and **Lugat**.

---

## 🇬🇧 English

### 🎯 Purpose

This project supports children in becoming active, critical, and responsible users of information.

It helps learners practice:

- Creating research questions
- Choosing effective keywords
- Using catalogs and sources
- Evaluating source reliability
- Questioning Artificial Intelligence outputs
- Protecting personal information
- Understanding ethical information use
- Explaining what they learn in their own words

---

## 🧒 Characters

### KÂŞİF  
Represents curiosity, inquiry, and the beginning of the research journey.

### BİLGE  
Acts as the Artificial Intelligence guide. Bilge gives hints, but also reminds children that AI-generated answers must always be checked.

### LUGAT  
Represents sources, evidence, dictionaries, catalogs, and verification skills.

---

## 🧩 Portal Features

The portal includes:

- Interactive workshop screens
- Research question missions
- Source and evidence checking activities
- AI response evaluation tasks
- Privacy and safety activities
- Mini games
- Points, badges, and progress tracking
- Information Guardian Certificate
- Child-friendly visual interface
- Touch-friendly interaction design
- Single-file HTML structure

---

## 🏆 Certificate System

After completing the workshop missions, participants can earn an **Information Guardian Certificate**.

The certificate shows that the participant has completed tasks related to:

- Creating research questions
- Using catalogs and sources
- Building evidence chains
- Checking Artificial Intelligence responses
- Understanding privacy and ethical information use

---

## 💻 How to Use

This project is built as a single HTML file.

### Run locally

1. Download the project files.
2. Rename the main file as `index.html`.
3. Open `index.html` in a browser.
4. The portal will run directly.

No server, installation, or additional package is required.

---

## 🌐 Publishing with GitHub Pages

To publish the portal with GitHub Pages:

1. Upload the project to a GitHub repository.
2. Rename the main HTML file as `index.html`.
3. Go to the repository settings.
4. Open the **Pages** section.
5. Select the `main` branch and `/root` folder.
6. GitHub will generate a public Pages link.
